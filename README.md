Neon Tide is a 2D top-down open-world crime game in Port Meridian, a fictional sun-soaked harbour city. Walk the streets or steal a car and drive, dodge traffic and pedestrians, and work four jobs for Mara Voss — The First Job, Shake the Heat, Harbor Heist and Deadline Dash — while a 5-star wanted system and police keep the heat on. A HUD with a minimap tracks every objective, and progress saves between sessions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static file server. No build step, no network requests.

## Controls

- **WASD** — move on foot
- **Mouse** — aim
- **Hold click** — fire
- **E** — steal / enter a car
- **Shift / Right-click** — dash (brief invulnerability)
- **Wanted** — 0–5 stars; police chase on foot and in cars.

## Missions

Work all four jobs for Mara Voss:

1. **The First Job** — prove yourself with a simple pickup and drop-off.
2. **Shake the Heat** — lose the cops tailing you after a job goes loud.
3. **Harbor Heist** — hit the harbour and get out with the goods.
4. **Deadline Dash** — race the clock across Port Meridian before time runs out.
